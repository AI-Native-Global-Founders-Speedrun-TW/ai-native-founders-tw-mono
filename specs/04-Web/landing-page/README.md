# Landing page 文案

這裡維護首頁、加入頁與 Credits 的閱讀版本。每份依頁面敘述順序保留標題與正文，讓讀者直接看懂對外說明；按鈕、欄位提示及狀態訊息依用途集中，不照網頁元件逐行抄錄。各頁可單獨閱讀，共用的品牌與導覽文字由下方入口查閱。

| 頁面 | 閱讀內容 |
|---|---|
| [首頁文案](<[文案]首頁.md>) | 組織目的、創業知識方向、出海階段、流派、參與者、AI-Native 實踐及加入邀請。 |
| [加入頁文案](<[文案]加入頁.md>) | 加入說明、四步路線、自介產生器、提交提醒與 FAQ。 |
| [Credits 文案](<[文案]Credits.md>) | 貢獻如何署名、名單來源，以及如何補充自己的貢獻資料。 |

## 維護方式與範圍

正文沿用現行文案的敘述、限定與語氣；同一標題下的連續文字整理為段落，真正並列的項目才用清單。合併重複控制文字、移除純版面定位標籤時，不得刪掉條件、承諾、問題、表單要求或例外。新增或修改對外主張仍須有來源及採納依據。

文案最初由網站 repo 的繁體中文 YAML 萃取；現行文案由本 package 維護，網站 YAML 與頁首頁尾元件承接實作，不反向制定規則。署名資料依 Credits 來源。動態人數與名單應由實際資料產生，本文不填假數字或假人名。

這次只調整文案文件的呈現與位置；不因此宣稱網站已同步。
