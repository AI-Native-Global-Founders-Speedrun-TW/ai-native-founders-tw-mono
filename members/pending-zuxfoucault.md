## 我正在 build 的產品或專案

目前還沒有在做商業產品，手上的東西都是開源的 agent 專案：

- **[MetaScientist](https://github.com/zuxfoucault/Meta_Scientist)**：會自我改進的 agentic 研究框架，用 LLM 多代理人搭配蒙地卡羅樹搜尋，自動尋找量子機器學習的演算法流程，內含網路搜尋、任務規劃與雙層研究迴圈。這是 QTML 2025 那篇論文背後的實作。
- **[DDB Knowledge Agent](https://github.com/zuxfoucault/ddb-knowledge-agent-py)**：串流式的 RAG agent，把向量相似度檢索和全文檢索用 RRF 融合，加上 ReAct 工具呼叫、依問題複雜度分流模型、語意快取與成本稽核；資料庫跑在 rootless 容器上，可以部署在沒有 Docker 的叢集。
- **Coding-Agent Benchmark**：把 `pallets/flask` 一千六百多個已合併的 PR 轉成 100 個可自動評分的 coding agent 任務，測試集不是用猜的，而是實際 diff 正常與壞掉版本的測試結果決定。實測四個開源模型，分數相差七倍，而且「能不能聽懂指令、守住格式」比模型規模或是否為程式碼特化更關鍵。

## 為什麼想加入

我剛從多倫多回到台灣，現在正在學習怎麼創業。

過去十年我主要在做 AI/ML 的研究與工程，近幾年集中在 multi-agent LLM 系統：自己做過 agentic 的研究框架、coding agent 的評測，也在業界交付過 AI agent 專案。技術這一端我有一定的累積，但「怎麼把這些經驗變成一個真的能活下來的生意」，是我現在要從頭學的事。

我認同這個組織的精神，也覺得這正是我現階段需要的：不是再多讀一些資料，而是找到能一起往前走的夥伴。所以我想加入。

## 想要獲得什麼

- **釐清自己的 Founder-Market Fit。** 這是我現在最大的問題。我的積累在 AI agent、研究方法論與系統實作，但要對到哪個市場、解誰的問題，我還沒有答案。很想聽不同背景的人當初是怎麼找到自己位置的。
- **從研究跨到生意。** 我熟悉怎麼把一個問題結構化、怎麼驗證技術上成不成立，但「有人願意付錢」是另一回事。想理解這中間還要補上什麼。
- **找共同創辦人。** 我正在找能互補的共同創辦人，也想認識同階段、願意一起嘗試的人。

## 想分享什麼

**用 multi-agent 做自動化探索**：在目標還很模糊的時候，怎麼讓一群 agent 自己展開可能的方向、自己評估，再決定下一步往哪走。

這是我在 MetaScientist 裡實際做出來的東西——用 LLM 多代理人搭配蒙地卡羅樹搜尋，加上雙層的研究迴圈，讓系統自己去搜尋演算法設計的空間。我可以分享架構怎麼拆、搜尋跟評估怎麼接起來、哪些地方容易爆掉，以及這套方法在研究以外還可以用在什麼地方。
